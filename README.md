## 7. Key Concepts Learned

### Semantic HTML

I learned that semantic HTML elements describe the purpose of different parts of a webpage. For example, I used `header` for the top part of the page, `nav` for navigation, `main` for the main content and `footer` for the bottom part.

### CSS Selectors

I used class selectors such as `.course-card`, `.nav-links` and `.card-button` to apply styles to specific parts of the page.

### Box Model

I used margin, padding and borders to control the size and spacing of elements. I also used `box-sizing: border-box` so padding and borders are included in the element's size.

### Flexbox

I used Flexbox for the navigation bar. It helped me put the logo and navigation links in a row and align them properly.

### Grid

I used CSS Grid for the course cards. On a large screen there are three cards in each row, which makes the six cards easier to organise.

### Typography

I used Arial as a simple readable font. I also changed font sizes and font weights for headings, navigation links and card information.

### Spacing

I used padding and gap to create space between sections, navigation items and cards.

### Hover Effects

I used the `:hover` selector to change the colour of navigation links and buttons. I also made the cards move slightly upward when the mouse is over them.

### Responsive Design

I used media queries to change the layout. The page shows three cards per row on a desktop, two cards per row on a tablet, and one card per row on a mobile screen.

## 8. Challenges and Solutions

### Challenge 1 — Making the cards fit properly

At first I was not sure how to place six cards without making the page look crowded. I learned about CSS Grid and used `grid-template-columns` to make three columns on a large screen.

### Challenge 2 — Making the page responsive

I had difficulty understanding how the same page could work on both a computer and a phone. I solved this by using media queries. I changed the card layout to two columns for tablets and one column for smaller mobile screens.

### Challenge 3 — Keeping the cards similar in height

Some descriptions have different lengths. I used Flexbox inside each card so the course information and button stay near the bottom of the card.
